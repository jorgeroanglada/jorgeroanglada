## Proyecto destacado

### [tg_mt5_bot](https://github.com/jorgeroanglada/tg_mt5_bot): señales de Telegram → MetaTrader 5 con IA

Un bot que lee mensajes de un grupo de Telegram escritos cada vez de una forma distinta, los convierte en acciones con IA (Gemini/Groq) y las ejecuta en MetaTrader 5, con barreras de seguridad para que la IA no haga nada si no está segura.

- Python · Telethon · API de Gemini/Groq · MetaTrader 5
- Pruebas automáticas que se ejecutan en cada cambio con GitHub Actions
- Proyecto de aprendizaje, probado solo en cuenta demo
